온결브로우 배포본 v1.5.0

1. ZIP을 압축 해제합니다.
2. 압축 해제한 폴더 안의 모든 파일과 폴더를 GitHub 저장소 최상위에 업로드하여 기존 파일을 교체합니다.
   저장소 첫 화면에 package.json / scripts / assets / public / dist 가 보여야 합니다.
   ZIP 자체를 올리거나 파일 전체를 별도 하위 폴더에 넣지 마세요.
3. 변경사항을 운영 브랜치 main에 커밋합니다.
4. Cloudflare Pages 설정:
   Project name: suwon-ongyeol-brow
   Framework preset: None
   Build command: npm run build
   Build output directory: dist
   Root directory: 비워두기
   NODE_VERSION: 22
   SITE_URL: https://suwon-ongyeol-brow.pages.dev
   운영 브랜치가 main이 아니라면 PRODUCTION_BRANCH에 실제 운영 브랜치명을 추가하세요.
5. 최신 커밋으로 배포합니다. 과거 실패 배포의 Retry가 아니라 최신 커밋이 배포되는지 확인하세요.
6. 빌드 로그에 아래 문구가 보여야 이번 수정본입니다.
   ONGYEOL BUILD v1.5.0 — starting
   ONGYEOL BUILD v1.5.0 — complete; deploy directory: dist

public 폴더에는 실제 robots.txt / sitemap.xml / rss.xml이 포함되어 있습니다.
빌드는 최종 대표 주소와 공개 페이지 데이터로 이 파일들을 갱신하고 dist 루트에도 생성합니다.
네이버가 방문하는 주소는 /public/robots.txt가 아니라 /robots.txt입니다.

네이버 소유확인:
이 사이트용으로 발급받은 원본 naver....html 파일을 public 폴더에 추가한 뒤 커밋하세요.
빌드가 원본 파일을 dist 루트로 복사하므로 https://suwon-ongyeol-brow.pages.dev/naver....html 로 접근합니다.
현재는 실제 발급 파일을 받지 않아 인증 HTML을 포함하지 않았습니다.
메타 방식은 NAVER_SITE_VERIFICATION에 발급받은 content 값만 넣고 재배포하세요.
